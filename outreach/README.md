- Один файл на лид: `L-0001_<компания>.md`. Для корпоративных подарков допускается файл на сегмент.
- В каждом файле: пометка `ЧЕРНОВИК — не отправлено`, 2 варианта темы, текст письма (до 120 слов)
  или сообщения в мессенджер (до 60 слов), follow-up через 4–5 дней, канал и контакт с источником.
- Правила текста: раздел 6 `CLAUDE.md`.
