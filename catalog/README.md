# catalog/

| Файл | Что это |
|---|---|
| `price_opt.csv` | оптовый прайс, основной для юрлиц: категория, марка, наименование, кол-во в упаковке, цена опт |
| `price_retail.csv` | розничный прайс (≈ опт × 1,25): категория, марка, наименование, тара, ёмкость, кол-во в упаковке, цена |
| `source/` | исходные файлы от владельца (`price_opt.xlsx`, `price_retail.xls`) |

- Цены — только для внутренней оценки заказа. В письмах цены не называем.
- В оптовом прайсе марка и кратность упаковки указаны не у всех позиций (`не указана` / `не указано`);
  кратность бери из розничного прайса по совпадающей позиции.
- Если владелец пришлёт новые прайсы, положи их в `source/` и заново сгенерируй CSV.
