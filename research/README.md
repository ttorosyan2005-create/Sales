# research/

Заметки по сегментам и источникам, сырые выборки до квалификации.

- Один файл на запуск и сегмент: `ГГГГ-ММ-ДД_<сегмент>.md`, например `2026-10-30_armenian-caucasian-center.md`.
- В файле: источники с URL, найденные компании, что проверено, какие источники закрыты (капча, авторизация).
- Квалифицированные лиды переносятся в `data/leads.csv` после проверки на дубли и стоп-лист.
